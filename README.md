## Descrição do Projeto
O Clyvovet Nexus é uma aplicação voltada para a gestão integrada de Pets e Eventos Preventivos, desenvolvida com Java 17, Spring Boot 3.2.5 e PostgreSQL 15. A arquitetura segue o padrão de microsserviços conteinerizados via Docker, implantados na nuvem da Microsoft Azure utilizando Azure Container Registry (ACR) e Azure Container Instances (ACI).

Guia Completo de Deploy (Azure CLI)
Execute os comandos abaixo sequencialmente no seu terminal para provisionar toda a infraestrutura e realizar o deploy dos containers na nuvem da Azure.

Bash
# ==========================================
# 1. CRIAÇÃO DO RESOURCE GROUP E ACR
# ==========================================

az login
az group create --name rg-clyvovet_nexus --location canadacentral
az acr create --resource-group rg-clyvovet_nexus --name acrclyvovetnexus566022 --sku Basic --admin-enabled true
az acr login --name acrclyvovetnexus566022


# ==========================================
# 2. BUILD E PUSH DAS IMAGENS (DOCKER)
# ==========================================

# No diretório da Aplicação Java (Spring Boot)
docker build -t acrclyvovetnexus566022.azurecr.io/clyvovet-app:latest .
docker push acrclyvovetnexus566022.azurecr.io/clyvovet-app:latest

# No diretório do Banco de Dados (script_db)
docker build -t acrclyvovetnexus566022.azurecr.io/clyvovet-db:latest .
docker push acrclyvovetnexus566022.azurecr.io/clyvovet-db:latest


# ==========================================
# 3. DEPLOY DOS CONTAINERS NO ACI (AZURE)
# ==========================================

# Subindo o Container do Banco de Dados PostgreSQL
az container create \
  --resource-group rg-clyvovet_nexus \
  --name clyvovet-db \
  --image acrclyvovetnexus566022.azurecr.io/clyvovet-db:latest \
  --dns-name-label dbclyvovetnexus566022 \
  --ports 5432 \
  --registry-username acrclyvovetnexus566022 \
  --registry-password 1sqeCF7kRRgNNwUHM33sP6WPA9Zr4r7JlmVPH5uKcQaOVGBwggFaJQQJ99CIACBsN54Eqg7NAAACAZCR6g1e \
  --environment-variables POSTGRES_DB=clyvovet_nexus_db POSTGRES_USER=postgres POSTGRES_PASSWORD=421212 \
  --restart-policy Always \
  --os-type Linux \
  --cpu 1 \
  --memory 2 \
  --location canadacentral

# Subindo o Container da Aplicação Spring Boot
az container create \
  --resource-group rg-clyvovet_nexus \
  --name clyvovet-app \
  --image acrclyvovetnexus566022.azurecr.io/clyvovet-app:latest \
  --dns-name-label appclyvovetnexus566022 \
  --ports 8080 \
  --registry-username acrclyvovetnexus566022 \
  --registry-password 1sqeCF7kRRgNNwUHM33sP6WPA9Zr4r7JlmVPH5uKcQaOVGBwggFaJQQJ99CIACBsN54Eqg7NAAACAZCR6g1e \
  --environment-variables \
    SPRING_DATASOURCE_URL=jdbc:postgresql://dbclyvovetnexus566022.canadacentral.azurecontainer.io:5432/clyvovet_nexus_db \
